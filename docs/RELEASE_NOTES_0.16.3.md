# 我的宠物世界 · Lite 0.16.3（测试版）

像素创作、动作编辑与桌面陪伴。当前不包含乐园、联机或喂食系统。

## 本次变化

- 默认14位伙伴：5只小熊、4只龙、鼠大师及4位默认动物。
- 旧单独奶龙/耄耋猫不再出现，保留用户作品与旧记录。
- 包含0.16.2的单一数字/标点入口和命名时图片可见修复。
- 提供独立 Lite 源码与安装、构建、隐私及素材说明。

## 安装

多数手机选择 arm64-v8a APK；旧32位设备选择 armeabi-v7a。最低 Android8.0。包名 studio.cyberbeads.app.lite，版本号21；发布者APK沿用已有 Lite 测试签名，可覆盖安装旧 Lite，勿先卸载。自行编译的签名可能不同，请先导出作品。

这是 Debug 验收版，不代表正式应用商店发行。实测范围以源码中的 docs/VERIFICATION.md 为准；完整设备兼容与正式签名发行仍待完成。素材来源和授权待核实项见 ASSETS.md；本次整理不替原角色授权。
