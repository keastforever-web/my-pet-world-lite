# 安装与使用

## 选择安装包

在 GitHub 仓库的 Releases 页下载 APK 与 SHA256SUMS.txt。`arm64-v8a` 适用于多数现代安卓手机，`armeabi-v7a` 仅用于旧 32 位设备。x86_64 是开发测试架构，不是普通手机的首选。

首次安装时，Android 可能要求允许此次文件来源安装应用。当前包是 Debug 测试版，不声称已通过商店审查或所有设备的安全软件检测。如设备检测阻止安装，请保留提示反馈维护者，不建议关闭系统防护。

## 升级和备份

发布者提供的 0.16.3 APK 包名为 `studio.cyberbeads.app.lite`、版本号21，沿用旧 Lite 测试签名。直接覆盖安装，通常无需卸载。完整版和 Lite 包名不同，数据不会自动互通。

自行编译或 CI 下载的 APK 默认使用自己的调试密钥，签名通常不同。如果系统显示签名冲突，先导出重要的 `.cyberpet` 文件和作品，再决定是否更换安装；不要直接删掉已有应用。Android 私有目录中的数据会随卸载清除，工程已关闭系统自动备份。

## 第一次使用

1. “创作”页可导入图片、试用像素猫或自由绘画，完成后保存作品。
2. 在“宠物”页选择伙伴，按引导授予悬浮窗权限，再带到桌面。通知用于让桌面服务持续可见和一键收回。
3. 点击宠物获得反馈，长按选择动作；聊天功能需在设置填写自己的 HTTPS 接口、模型和密钥。

不配置接口也能使用本机创作、动作编辑与桌面陪伴。接口可能产生服务商费用，应用不代为购买，不内置共享账号。中文朗读依赖设备已经安装的中文 TTS。

## 已知限制

Android8–12 的桌面触摸范围有矩形降级，Android13+支持轮廓触摸。厂商后台和悬浮窗策略可能影响持续显示；请按实际手机权限页面处理。横屏手机键盘占用空间较大时，命名预览会缩小。当前没有 iOS 安装包、账号系统、云同步或多人乐园。
